## 🧠 منطق عملکرد سیستم

این سیستم بر پایه چند بخش اصلی کار می‌کند:

### 1. مدیریت داده‌ها

تمام اطلاعات در دو لایه ذخیره می‌شوند:

* **SQLite Database** → برای ذخیره‌سازی پایدار و ساخت‌یافته
* **Excel File** → برای گزارش‌گیری و استفاده خارج از سیستم

---

### 2. ثبت معاملات (قولنامه)

در زمان ثبت هر معامله:

* یک **شماره یکتا (Unique ID)** به‌صورت خودکار تولید می‌شود
* از این شماره برای:

  * جلوگیری از تکرار
  * شناسایی هر معامله
  * نام‌گذاری فایل خروجی

استفاده می‌شود

---

### 3. جلوگیری از تکرار

سیستم با استفاده از:

* بررسی شماره قولنامه
* و داده‌های ثبت‌شده قبلی

از ثبت معاملات یا اطلاعات تکراری جلوگیری می‌کند.

---

### 4. تولید خروجی

برای هر معامله:

* یک فایل خروجی (تصویر یا فایل) تولید می‌شود
* نام فایل شامل:

  * شماره قولنامه
  * مشخصات معامله

مثال:

```id="ex1"
contract_1023_peugeot206.jpg
```
